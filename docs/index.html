鱼压 · YUYA

拖入文件，轻松压缩与解压。全程在您的 Mac 本机完成，纯粹、安全、轻巧。

核心特性

📦 打包分享

支持多文件合成 ZIP 格式，提供更快、均衡、更小三种压缩率选择。

🔍 解压与预览

支持 ZIP、7Z、RAR、TAR、GZIP 等常见格式；无需解压即可快速查看包内目录。

🔒 隐私与沙盒

完全遵循 macOS 沙盒安全机制，不申请网络权限，零数据收集与上传。

⚡️ 原生轻盈

基于 Swift 原生开发，适配 Apple 芯片与 Intel 架构，启动迅速，不占内存。
